# Slope Plus Mod
hi this is a mod for [Slope Plus by Coweggs](https://coweggs.itch.io/slope-plus/), run using [Melon Loader](https://github.com/LavaGang/MelonLoader)


# To Install

Download both Slope++.dll and SPPAssets.zip. Put the .dll file in your melon loader Mods folder. Extract the .zip file into the Slope Plus directory.


# Changes

- The quit game button now goes to the main menu instead of closing the application
- Added 1 secret seed
